# Smart Calculator

A small command-line calculator written in Python, used to practise Git and GitHub:
branching, committing, merging and resolving a merge conflict.

**Version:** 1.2 (division by zero shows an error message; division results are rounded to 2 decimal places)

## Run

```
python3 calculator.py
```

Type an expression such as `12 / 4`, or `exit` to quit.

## Test

```
python3 -m unittest -v
```
